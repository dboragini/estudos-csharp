# Estudos de C# e .NET

Exercícios dos meus estudos de **C# e .NET**. Sou estudante de Análise e Desenvolvimento de Sistemas na Faculdade Impacta e trago mais de 10 anos de experiência em infraestrutura e suporte de TI.

## Conteúdo

| Pasta | O que tem | Conceitos praticados |
|---|---|---|
| `Aula1` | Programa que pergunta nome e idade | Variáveis, tipos, leitura de dados, `int.Parse`, operador `??` |
| `Exercicio01-Calculadora` | Calculadora com as 4 operações | Operadores aritméticos, `double`, cast, formatação `:F2`, proteção contra divisão por zero |
| `Aula2-If` | Maioridade e situação do aluno pela nota | `if`, `else if`, `else`, operadores de comparação |
| `Aula3-Repeticao` | 6 exercícios com laços de repetição | `for`, incremento e decremento, `if` dentro do `for`, operador `%` |

## Como rodar

Com o [.NET SDK](https://dotnet.microsoft.com/download) instalado, entre na pasta do exercício e execute:

```
dotnet run
```
